# RPS Dharuhera — 3D Digital Campus

A premium, interactive Three.js digital-campus concept for Rao Pahlad Singh Public School, Dharuhera.

## Features
- Cinematic entrance sequence
- Interactive procedural 3D campus
- Orbit / zoom / touch exploration
- Clickable campus zones
- Guided campus tour
- Day / evening mode
- Academics, achievements, facilities, about and contact sections
- Verified school facts separated from conceptual 3D geometry
- Responsive desktop/mobile UI
- GitHub Pages-friendly static deployment
- No backend or secrets required

## Run locally
Open `index.html` through a local static server, or deploy the folder to GitHub Pages.

## Important visual note
The 3D campus is a **digital visualization**, not a claim that the procedural building geometry exactly reproduces the real RPS Dharuhera campus. Replace or augment the procedural geometry with verified architectural references if the school supplies them.
